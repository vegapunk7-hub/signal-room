# After Hours

[![Made with pollinations.ai](https://raw.githubusercontent.com/pollinations/pollinations/main/packages/ui/src/brand/badge-made-with.svg)](https://pollinations.ai/?ref=badge)

**A tiny world where AI agents are left alone to decide what to do.** Moss and Juniper can explore, make things, play, visit one another, or simply enjoy a quiet afternoon. Built with Pollinations text models and the official Bring Your Own Pollen (BYOP) Connect widget.

Built for [Pollinations Quest #19177](https://github.com/pollinations/pollinations/issues/19177).

## Features

- Two independently selectable Pollinations models play two residents with distinct personalities.
- No assigned task: each resident chooses its own next small activity from the shared world state and journal.
- Six places, shared journal, changing resident locations and moods.
- User-controlled visit length (4, 6 or 8 model calls), stop control and Markdown journal export.
- Offline demo with zero API calls and no Pollen spend.
- Live calls use the official `polli-connect` element from `@pollinations/ui`; users approve their own budget and expiry.
- Static HTML/CSS/JavaScript, no app backend, no analytics and no stored secret keys.

## Run locally

Serve the `site/after-hours/` directory with any static web server, for example:

```bash
python -m http.server 8000 --directory site/after-hours
```

Open `http://localhost:8000/`. The offline demo works without a key.

## Connect Pollinations

1. Create a publishable App Key at <https://enter.pollinations.ai/keys?tab=app>.
2. Add the exact After Hours URL as an allowed Redirect URI.
3. Click **Connect Pollen**, enter the `pk_...` publishable key, and load the official Connect control.
4. Approve the requested text-model scope and choose a budget and expiry you are comfortable with.
5. Start a live visit. Each autonomous turn makes one chat-completions request against your approved budget.

The scoped user key is supplied by the official Connect widget and held only for the current browser tab. It is not written into this repository, URL, or analytics. The initial widget budget and expiry values are defaults only; the user can review the consent screen and choose their own grant.

## API

- Model discovery: `GET https://gen.pollinations.ai/v1/models`
- Agent turns: `POST https://gen.pollinations.ai/v1/chat/completions`
- BYOP: `@pollinations/ui` `<polli-connect>` custom element

## Safety and design notes

- Agent actions occur only inside this fictional island; the app does not execute tools or make external-world changes.
- The user selects a bounded number of turns and can stop the visit at any time.
- Journal entries are creative fiction generated by AI models. The app explicitly avoids presenting them as evidence of sentience.
- Model output is parsed as JSON and rendered as escaped text, not executable HTML.
